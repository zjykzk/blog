# Book Mastery Rubric

对每个被抽样的承重知识点，在五个维度上记录 `0 / 1 / 2`。数字用于保持判定一致，不替代证据描述。

| 维度 | 0 | 1 | 2 |
|---|---|---|---|
| 准确重建 | 缺失或有实质错误 | 提示后正确，或遗漏非致命条件 | 无提示且准确，保留关键限定 |
| 结构解释 | 只能给结论或术语 | 能解释部分关系，但因果/依赖不完整 | 能完整说明为什么以及各部分怎样连接 |
| 概念辨析 | 混淆相邻概念或常见误读 | 经追问后能区分 | 能主动给出判别条件和反例 |
| 陌生迁移 | 不会应用或机械套词 | 方向正确但遗漏关键变量 | 在新情境中正确调整模型并说明理由 |
| 边界与修正 | 把主张绝对化，反证后仍不修正 | 能承认例外但边界模糊 | 能说明失效条件，并据新证据改写判断 |

## 判定规则

不要只看总分，先检查门槛：

- 核心问题和主结构若存在实质错误，最高为“可复述”。
- 没有完成两个陌生迁移，最高为“结构性理解”。
- 迁移平均低于 2，不能判“可迁移掌握”。
- 没有边界测试，不能判“可迁移掌握”。
- 使用提示后完成的项目，当前轮该维度最高记 1。
- 测试中讲解后才答对，记录为“本次补学”，不要改写为测试前已经掌握。
- 未经过至少 24 小时的无提示复测，不能判“稳固掌握”。

## 书型适配

### 论证或方法书

- 准确：主张、前提和关键证据没有偷换。
- 结构：能够重建论证链，不只是列观点。
- 辨析：能区分作者方案与相邻方案。
- 迁移：能在新问题中使用方法，并选择何时不用。
- 边界：能提出反例、代价或证据限制。

### 历史或传记

- 准确：人物、时序和关键事件不颠倒。
- 结构：区分先后、相关、条件与因果。
- 辨析：区分当时材料、后来回忆和作者解释。
- 迁移：能用同一机制分析另一历史局面，但不机械类比。
- 边界：知道反事实不等于已经发生的证据。

### 文学

- 准确：人物关系、主要变化和结尾没有误读。
- 结构：能说明叙事、意象或形式如何改变理解。
- 辨析：保留文本允许的歧义，不把主题压成一句鸡汤。
- 迁移：能比较另一个人物选择或相似处境。
- 边界：区分文本依据与个人阐释。

### 技术或科学

- 准确：概念、单位、步骤和结论正确。
- 结构：能从条件推到机制、预测或结果。
- 辨析：能区分相邻模型和适用前提。
- 迁移：能解决一个没有照抄原例的新问题。
- 边界：能指出模型何时失效以及还缺什么证据。

## 证据记录

每道题只记录可复核证据：

```text
知识点：
题型：重建 / 解释 / 辨析 / 迁移 / 边界
是否提示：否 / 一级提示 / 二级提示
回答证据：用户实际说清了什么
缺口：哪条关系、条件或事实仍不成立
本轮结果：独立通过 / 提示后通过 / 测试中补学 / 未通过
```
