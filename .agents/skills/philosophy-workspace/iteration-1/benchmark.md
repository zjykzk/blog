# Skill Benchmark: philosophy

Each of the three scenarios was run once with the skill and once without it.

| Metric | With skill | Without skill | Delta |
| --- | ---: | ---: | ---: |
| Expectations passed | 15 / 15 | 9 / 15 | +6 |
| Pass rate | 100% | 60% | +40 pp |
| Mean output characters | 5,149 | 2,657 | +2,492 |

The skill's clearest contribution was forcing every answer to state what the theory hides and what evidence would require changing the judgment. Baseline answers usually explained the philosophy well, but stopped before an explicit falsifier.

The main cost was length: the skill-guided answers were about 94% longer. This is acceptable for deep reading, but short questions should use the compressed route already allowed by `SKILL.md`.

Timing and model-token data were unavailable from the evaluation runner. Character counts are reported only as an output-size proxy, not as token counts.
