# Seeing Clearly

看透不是给人贴上更锋利的标签，而是找到什么关系和机制在稳定生成眼前的结果，并允许现实推翻自己的解释。

## Core Formula

```text
透彻判断 = 事实 + 重复模式 + 约束与激励 + 竞争解释 + 可验证预测
```

一个解释是否透彻，可以检查三件事：它能否同时解释多个已经发生的现象，能否预测下一次会发生什么，以及能否指出改变哪个条件会让结果变化。

## Principle

分析的对象不是“这个人本质上是什么”，而是“在什么条件下，哪些变量通过怎样的选择和反馈，反复产生了什么结果”。人格标签会提前关闭调查；结构描述则保留了证据、边界和修改判断的入口。

理解行为的成因不等于替行为免责。结构分析负责提高判断的准确度，责任判断仍要依据行为、影响、证据和边界。

## Operating Flow

### 1. 分开事实、解释与情绪

- **事实**：可观察、可核对的言行与结果。
- **解释**：对动机、人格和因果的推断。
- **情绪**：事件在观察者身上激起的感受。

事实是分析的硬地板。解释可以保留为假设，情绪可以提供“哪里对我重要”的线索，但两者都不能直接冒充事实。

### 2. 寻找跨场景的重复结果

单次事件只能支持弱判断。观察一个人时，优先比较其在有利益、有压力和缺少监督时如何分配利益、承担代价、处理边界和接受反馈。面对相似成本时反复出现的选择，比一句表态更能暴露稳定模式。

如果没有重复结果，更可能是一次事件而不是稳定结构，此时应降低结论强度。

### 3. 抽出生成结构

用 [[wiki/concepts/Mechanism Model|机制模型]] 检查六项：结果、关键变量、约束、激励、反馈和时间。

```text
结果：什么事情反复发生？
变量：哪 2–5 个因素一变，结果就会明显变化？
约束：参与者有哪些选择实际上做不了或代价过高？
激励：什么行为得到收益，什么行为承担代价？
反馈：哪种行为正在被放大或纠正？
时间：这个模式如何积累、固化或反转？
```

最终将解释压成一句机制句：

> 在某种约束下，几个关键变量通过某种激励和反馈，随着时间持续生成某个重复结果。

### 4. 保留竞争解释

第一个自洽解释通常只是候选。至少保留两个能够解释同一事实的替代假设，并为它们写出不同预测。

例如，一个人反复推卸责任，可能源于稳定的利己策略、过去背锅形成的过度自保，也可能源于组织中“谁负责谁吃亏”的结算机制。只有当这些解释能预测不同条件下的不同行为时，才有办法比较它们。

### 5. 用小变化验证判断

通过一个低风险干预改变关键条件：把口头约定改成书面责任表、让贡献与责任可追溯、拒绝一次不合理兜底，或观察对方在没有直接利益时是否仍然行动。

- 条件改变后行为也改变，说明环境、约束或激励可能是主因。
- 条件改变后模式依旧稳定，个人策略更可能是主因。
- 行为只对特定对象出现，权力或依赖关系可能是关键变量。

这一步把直觉推进为 [[wiki/concepts/Causal Reasoning|干预判断]]：不只解释已经发生的事，还检查主动改变候选原因后，结果是否真的变化。

## Quality Checks

一个合格的“看透”应通过以下检查：

1. **压缩性**：一个结构能解释多个现象，而不是为每件事临时编故事。
2. **预测性**：它能提前说出下一次更可能发生什么。
3. **可干预性**：它能指出改变哪个条件可能改变结果。
4. **可证伪性**：它明确说明什么证据会迫使自己改口。

如果解释只能描述过去、不能区分替代假设，也没有任何改口条件，它更接近叙事，而不是透彻判断。

## Common Failure Modes

1. **用单次事件定义整个人**：把一次失误直接升级为稳定人格。
2. **把猜动机当作事实**：解释越生动，越容易产生“已经看穿”的错觉。
3. **只寻找支持材料**：忽略对自己判断不利的行为和情境。
4. **把系统行为归咎于个人品德**：忽略规则、奖励、权力和风险分配。
5. **把理解等同于宽恕**：看懂成因之后，仍然需要判断伤害并守住边界。

## Practical Template

```text
事实：
重复结果：
我的解释：

```
