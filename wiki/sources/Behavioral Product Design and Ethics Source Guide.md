# Behavioral Product Design and Ethics Source Guide

产品经理真正需要的不是“催眠用户”，而是理解行为如何被目标、能力、注意、期待、选择架构、环境线索和反馈共同生成。行为设计不可避免地影响用户；专业边界在于影响是否透明、可理解、可拒绝、可撤回，并与用户自己认可的长期结果一致。

## 核心教材

| 书 | 作者 | 用途 | 建议读法 |
|---|---|---|---|
| *Designing for Behavior Change: Applying Psychology and Behavioral Economics* | Stephen Wendel | 面向产品经理、设计师和数据分析师，把目标行为、障碍诊断、干预设计和实验串成流程 | **产品主教材**；带一个真实激活或留存问题逐章做练习 |
| *Persuasive Technology: Using Computers to Change What We Think and Do* | B. J. Fogg | 奠定 Captology：计算机如何作为工具、媒介和社会行动者影响态度与行为 | 读历史框架和伦理章节，再用当代移动产品重画案例 |
| *Tiny Habits* | B. J. Fogg | 用 `B = MAP` 和微行为方法解释动机、能力、提示与习惯形成 | 用于诊断“用户为什么没做”，先降难度再加动机 |
| *Nudge: The Final Edition* | Richard H. Thaler、Cass R. Sunstein | 建立选择架构、默认项、反馈和自由家长主义框架 | 重点读 choice architect、默认项、sludge 和新版反思 |
| *Thinking, Fast and Slow* | Daniel Kahneman | 判断偏差、框架、损失厌恶、锚定和有限注意的共同语言 | 不背偏差清单；把每个机制写成可反驳的产品假设 |
| *Hooked: How to Build Habit-Forming Products* | Nir Eyal | 用 trigger—action—variable reward—investment 描述习惯产品循环 | 作为**描述性拆解工具**；必须和伦理、福祉指标对读 |
| *Evil by Design* | Chris Nodder | 从“七宗罪”视角展示说服与操控模式 | 红队教材：识别自己方案如何利用社会证明、稀缺和摩擦 |
| *Ruined by Design* | Mike Monteiro | 把设计后果、组织责任和拒绝有害工作放回职业伦理 | 用于团队讨论责任，不是行为科学教材 |
| *Manipulation* | Cass R. Sunstein | 区分可接受影响、nudge 与损害自主性的操控 | 建立伦理词汇，讨论透明、能动性、福祉和选择权 |

## 免费材料、视频与课程

### Irrational Labs — Behavioral Design

- [Behavioral Design PDF](https://irrationallabs.com/content/uploads/2020/05/IL-BehavioralDesign.pdf)：面向产品经理、设计师和研究者的短指南，主线是行为诊断、定义关键行为、减少心理和流程障碍。
- [Behavioral Design Bootcamp](https://behavioraleconomicsbootcamp.com/behavioraldesignonline/)：八周课程，覆盖关键行为、3B、认知过载和实验。

适合：希望把阅读迅速转成一个真实 onboarding、activation 或 retention 项目的人。限制：商业课程页面不是独立效果证据。

### B. J. Fogg — Behavior Model

[BJ Fogg 官方模型](https://www.bjfogg.com/home) 将行为写为 `B = MAP`：Motivation、Ability 和 Prompt 在同一时刻相遇。它的产品价值是把“用户不够想要”拆成三个可设计变量，尤其优先检查能力与提示。

### Nielsen Norman Group — Deceptive Patterns

[Deceptive Patterns in UX](https://www.nngroup.com/articles/deceptive-patterns/) 定义：通过欺骗、误导、羞辱或阻碍用户选择，使用户采取更有利于公司的行动。文章强调这类模式会带来金钱、隐私和法律控制损失，对时间不足、识字或数字素养较低的用户更有效，因此设计师应主动反对。

### FTC — Bringing Dark Patterns to Light

[FTC 报告与新闻稿](https://www.ftc.gov/news-events/news/press-releases/2022/09/ftc-report-shows-rise-sophisticated-dark-patterns-designed-trick-trap-consumers) 把伪装广告、难以取消、隐藏条款和费用、诱导交出数据列为典型做法。它提醒团队：短期转化实验赢了，不代表法律、信任和长期价值上也赢。

### SCEH / ASCH 公开视频与课程

- [SCEH Webinars](https://www.sceh.us/webinars) 和 [SCEH Academy](https://www.sceh.us/sceh-academy) 是临床专业继续教育，不是产品增长课。
- [ASCH Hypnosis Questions & Answers](https://asch.net/wp-content/uploads/2024/04/tk_questions_and_answers.pdf) 用于去除“控制意志、真话药、睡着、恢复完美记忆”等神话。

产品经理观看它们的目的，是理解注意、建议、期待、个体差异和同意，而不是学习对用户“施术”。

## 从机制到产品动作

| 机制 | 合法产品动作 | 验证指标 | 常见误用 |
|---|---|---|---|
| 聚焦注意 | 减少噪声、单一主任务、渐进披露 | 完成率、错误率、理解度 | 隐藏价格、替代项或退出入口 |
| 期待 | 清楚说明将发生什么、结果范围与时间 | 预期校准、信任、结果达成 | 夸大承诺、伪造稀缺和社会证明 |
| 暗示与框架 | 用准确标签、示例和默认项帮助理解 | 选择质量、后悔率、撤回率 | 用羞耻、恐惧或歧义迫使同意 |
| 能力 | 缩短步骤、预填可逆信息、即时帮助 | 时间、失败点、支持请求 | 让购买容易而取消困难 |
| 提示 | 在用户有意图且有能力时提醒 | 有效行动、关闭率、投诉率 | 高频打扰、利用脆弱时刻 |
| 反馈与强化 | 反馈真实进展、庆祝用户价值 | 长期结果、留存质量 | 只奖励打开次数或无意义 streak |
| 社会证明 | 展示真实、相关、可核验的行为 | 理解、信心、决策质量 | 伪造人数、隐藏样本和反例 |
| 个体化 | 根据明确目标调整路径 | 目标达成、可控性、公平性 | 推断脆弱性并定向施压 |

## 产品经理的研究模板

### 1. 定义目标行为

写成可观察事件，而不是抽象态度：

- 差：让用户更重视健康；
- 好：用户在每周日晚为下一周选择三个可执行训练时段。

同时写出用户结果与公司结果，检查二者是否可能分离。

### 2. 画行为链

记录：情境 → 注意 → 解释 → 期待 → 动作 → 即时结果 → 延迟结果。
在每一步标注证据：访谈、自述、日志、观察、实验或推断。

### 3. 先诊断能力和摩擦

在添加奖励、焦虑、稀缺或推送前，先问：

- 用户知道下一步吗？
- 动作是否太复杂？
- 是否缺少权限、时间、钱、技能或信任？
- 系统是否在错误时机打扰？

### 4. 设计最小干预

每次只改变一个主要机制，预先写明：

- 假设；
- 中介变量；
- 成功与伤害指标；
- 停止条件；
- 对脆弱用户的影响；
- 撤回和恢复路径。

### 5. 审计长期结果

除点击、转化、留存外，至少检查：

- 任务是否真正完成；
- 用户是否理解自己同意了什么；
- 是否产生后悔、投诉、退款或强迫使用；
- 退出是否对称；
- 用户福祉与信任是否下降；
- 差异是否集中在脆弱群体。

## 影响与操控的边界

可以用五问做设计评审：

1. **目标归属**：这个行为主要服务谁的目标？
2. **可见性**：用户能否看见关键影响、成本和替代项？
3. **可拒绝性**：拒绝是否真的可行，而不是被惩罚性摩擦阻碍？
4. **可撤回性**：同意、订阅、数据和默认项能否轻松撤回？
5. **结果一致性**：短期行为是否改善用户按自己标准认可的长期结果？

如果一个设计只能在用户没看懂、没时间、忘记取消或不敢拒绝时成功，它不是“更懂潜意识”，而是在利用认知与制度弱点。^[inferred]

## 不推荐作为主教材的材料

- “一句话控制任何人”“瞬间催眠成交”“NLP 读心成交”等无可靠证据的课程；
- 把脑波、左右脑、多巴胺或“爬虫脑”当万能解释的内容；
- 只展示转化率、不报告退出、后悔、投诉和长期结果的增长案例；
- 用催眠恢复前世、童年“真相”或法证记忆的材料；
- 把用户研究改造成诱导性审讯的话术库。
