因为人的物理存在、无限欲望、世界存在约束，欲望的导向新的物理存在状态+世界的约束于是出现了问题

```
                    [有生命的身体存在]
                             |
                             v
                   [维持生命需要一定条件]
                             |
                      感受、学习与解释
                             |
                             v
   [社会生活与经验] ------> [具体欲望 / 目标]
                             |
                             v
                           [行动]
                             |
                             v
                  [维持或改变自身与环境]
                             |
                             +----> 影响后续需要与欲望


```



## 问题

问题的产生：因为欲望，产生了差距，以及约束

欲望：区分自然需求和非自然需求，也就是活着的必要欲望以及超过活着的欲望

约束：自然约束、社会关系（生产+分配+占有）

## 循环

人通过解决问题改变自身与环境的状态；身体消耗、欲望变化，以及行动带来的后果，又可能形成新的不匹配，使问题解决持续发生。



                    [当前状态 + 当前需要/目标]
                                |
                                v
                    [出现值得处理的不匹配]
                                |
                                v
                           [行动 / 解决]
                                |
                                v
                             [新状态]
                                |
               +----------------+----------------+
               |                |                |
           身体或环境变化     满足标准提高      行动带来新后果
               |                |                |
           原需要再出现       新目标形成      新需要或新约束
               |                |                |
               +----------------+----------------+
                                |
                                v
                    [再次与现有条件相比较]
                                |
                    +-----------+-----------+
                    |                       |
                能够顺利满足             满足受阻
                    |                       |
               维持 / 例行处理         进入下一轮问题
