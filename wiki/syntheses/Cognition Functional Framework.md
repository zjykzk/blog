# 认知功能框架：相互作用、反馈与意识边界

认知涉及感知、注意、记忆、表征、推理、决策与行动等相互作用的过程，并受到目标、情绪、身体状态和环境反馈的影响。把这些过程画成双向联系的功能模块，有助于理解它们如何配合；模块数量、位置与连线是解释性选择，不构成一套公认的完整认知架构。^[inferred]

> [!important] 证据范围
> 参考研究支持自上而下影响、执行功能、情绪与认知交互、元认知测量等具体论点。本页对它们的组合与图示排布属于综合解释。自我表征、元认知与主观体验之间的关系不能视为已经解决。

## 背景：为什么“完整六层结构”容易造成误解

原始图以“从底层到顶层：认知能力的完整结构”为题，依次排列信息处理、记忆、表示、结构化、模型运算和高级认知，并用闭环解释行动反馈，用自我模型解释“我”的形成。原图来自对话内图片，作者及外部出处未确认；其分层和意识主张是评审对象。

这类图容易把四种不同的问题放在同一条纵轴上：

| 分析维度 | 回答的问题 | 不能直接推出什么 |
|---|---|---|
| 能力分类 | 人能完成哪些任务？ | 不能仅由名称确定能力高低或发展顺序 |
| 功能与过程 | 信息怎样被选择、保持、加工并用于行动？ | 不能自动得到一条所有任务必经的流水线 |
| 生物实现 | 这些过程怎样由神经系统和身体实现？ | 不能把每个功能模块直接对应一个独立脑区 |
| 自我与意识理论 | 自我信息怎样组织？为什么存在主观体验？ | 不能由控制、自我监测或模型更新直接证明意识 |

层次模型可以有用，但需要说明层次按什么划分、哪些关系已有证据、哪些只是便于讲解的安排。把分类画成阶梯，本身并不提供这些证明。^[inferred]

## 六层图中可保留的洞见与需要修正的主张

| 图中表达 | 可保留的洞见 | 修正理由与边界 |
|---|---|---|
| 感知—建模—推理—决策—行动—反馈—更新 | 行动会改变输入，结果会影响后续认知 | 复杂任务的简化模型；习惯、熟练动作等不必每次经过显式建模和推理 |
| 区分、关联、比较、预测属于最底层 | 这些操作在多种任务中反复出现 | 感知相似性比较与战略方案比较复杂度不同，不能凭操作名称统一定级 |
| 表示能力等于符号化 | 语言和符号让信息可以被操作、交流 | 表征也包括知觉、空间和动作形式；不都依赖显式文字或公式 |
| 表示、结构化、模型运算、高级认知逐级独立 | 可以区分材料如何表示与如何被操作 | 概念本身也是表征，因果分析也是推理，假设模拟涉及想象，边界存在重叠 |
| 高级认知建立在低级认知之上 | 某些复杂任务依赖基础过程 | 目标、知识与预期也会反向影响注意和知觉，不能只画向上的箭头 [1] |
| 元认知监控整个系统 | 人能评价把握度并调整策略 | 监测只覆盖部分过程，而且可能失准；自信不等于正确 [4] |
| 更新使系统不断进化 | 经验会改变后续表现 | 噪声、错误归因与选择性取样也可能强化偏差；个体学习不能直接等同于生物演化 |
| 自我模型产生“我”和意识 | 自我表征有助于解释部分自我判断与调节 | 属于理论视角；不能作为关于自我起源或主观体验的定论 [5][6] |

预测出现在多个层面并不自动构成错误。感知预期、基于显式模型的预测与长期情景规划可以分开讨论；问题在于必须说明所用信息、操作方式和任务复杂度的差别。^[inferred]

记忆分类也需要保持尺度一致：工作记忆与长期记忆可以作粗略区分，情景记忆通常属于长期记忆，三者不宜直接列为同级类别。

## 修订框架：功能模块与跨模块调节

以下六组模块用于组织阅读，允许功能交叉与并行，不主张六个独立认知器官，也不规定固定的执行顺序。^[inferred]

| 功能模块 | 主要作用 | 典型内容 |
|---|---|---|
| 感知与注意 | 获取信号并选择关注内容 | 外界感官、身体内部信号、注意分配 |
| 记忆与学习 | 保持和提取经验，改变后续表现 | 工作记忆、长期记忆、多种学习机制 |
| 表征与建模 | 表示对象，组织概念与关系 | 语言、图像、空间、动作、抽象关系 |
| 推理与模拟 | 形成推断，探索可能情况 | 因果推理、预测、想象、反事实模拟 |
| 评估与决策 | 权衡价值、成本和不确定性 | 方案比较、风险判断、选择与计划 |
| 行动与技能 | 执行动作并改变处境与输入 | 主动探索、熟练操作、习惯与自动化 |

理解、创造、系统思考和问题解决依赖多个过程配合，也依赖领域知识、经验和练习。它们不宜被理解为单独占据最高一层的功能盒子。^[inferred]

### 目标、动机与情绪参与整个过程

目标与需要影响注意分配、信息搜寻和行动方向；情绪与价值评估影响记忆、风险判断与选择。它们参与形成认知行为，不能仅在完成推理之后才作为附加因素出现。[3]

### 执行控制与元认知需要区分

执行控制包括抑制无关反应、保持和更新任务信息、在规则或策略间切换。常见执行功能框架强调抑制控制、工作记忆和认知灵活性；这些功能与注意、记忆等过程重叠。[2]

元认知指对自身认知活动的监测与调节，例如评估把握度、察觉理解困难，并据此检查、求助或改变策略。任务表现与元认知准确性可以分开衡量；一个人做得好，不意味着他总能准确判断自己何时做得好。[4]

执行控制和元认知都不宜被画成全知的内部“总指挥”。调节依赖有限资源，也会受到情境影响。^[inferred]

### 身体与环境属于不同解释维度

神经系统和身体参与认知的生物实现，疲劳、疼痛、饥饿和唤醒水平会影响表现。物理、社会与文化环境提供线索、工具和约束，行动又会改变这些条件。

基因与进化、个体发育和经验共同塑造认知系统。“基因—大脑—神经元—信息处理—认知”适合提示多个解释尺度，不宜当作互不重叠的单向生成阶梯。

## 用具体任务理解相互作用

**找钥匙。**“找钥匙”的目标首先引导注意，记忆提示可能的位置。移动视线、翻开物品带来新信息，发现或落空又改变下一步搜索。目标和经验并非等到感知完成后才参与。[1]

**判断一条消息。**消息可能先引起情绪反应，已有知识帮助理解，也可能带来偏见。检查来源、比较证据、评估把握度后，再决定是否相信或转发。这个例子同时涉及情绪、表征、推理、元认知和行动，难以用单向层级充分解释。^[inferred]

反馈只说明结果返回系统，并不保证系统向更可靠的判断移动。分析学习效果，还需要检查反馈质量、归因方式和更新规则；这一点可接到 [[wiki/concepts/Feedback Loops|反馈回路]]。^[inferred]

## 自我与意识：三个相关但不同的问题

| 概念 | 关键问题 | 示例与限制 |
|---|---|---|
| 自我表征 | 系统怎样表示自身？ | 关于身体、能力、身份和经历的信息；拥有这些信息不自动证明主观体验 |
| 元认知 | 系统怎样判断、调节自身的认知？ | “我不确定，需要再查证”；监测可能只覆盖部分过程，也可能判断错误 |
| 主观体验 | 为什么会有亲身感受到的经验？ | 疼痛的感受、看到红色的体验；其解释仍有理论争议 |

“当自我模型更新并产生主观体验时，就出现意识”没有解释意识起源，因为它把需要解释的“产生主观体验”放进了前提。能够记录自身状态、预测自身行为或监测错误，都不足以单独证明系统有主观体验。

把自我理解为用于预测或控制的一种模型，是理论视角之一；“自我就是为了预测和控制而产生的模型”不能当作已证实的演化结论。^[ambiguous]

自我研究还区分身体归属感、行动主体感、最小自我与叙事自我等方面。[5] 自我表征与主观意识如何关联仍存在争议；2025 年对全球神经工作空间理论和整合信息理论的联合检验，也没有确立一套无争议的统一意识解释。[6] ^[ambiguous]

“人生等于认知系统持续运行”属于哲学表达，不是由这张功能图直接推出的科学结论。

## 使用这类框架时的检查方法

评估一张认知图时，可以依次检查以下问题。这是一组从原图评审中提炼出的使用准则。^[inferred]

1. **分类依据是否一致？** 是否把能力、过程、表征形式、生物结构混在一条轴上？
2. **箭头到底表示什么？** 是先后顺序、必要依赖、因果影响，还是仅用于导览？有没有证据支持？
3. **能否解释反向作用与失败？** 目标怎样改变注意，行动怎样改变输入，错误反馈怎样强化偏差？
4. **功能描述是否越界成为意识证明？** 能自我表示、自我控制或自我监测，与有主观体验之间还缺少什么论证？

认知框架的实用价值在于帮助提出更清楚、可检查的问题。图形的整齐、术语的覆盖率和闭环的完整外观，都不能替代证据。
